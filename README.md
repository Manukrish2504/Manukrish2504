Software engineer. I mostly build developer tools for macOS.

### What I am working on

**[Perch](https://github.com/Manukrish2504/Perch)** turns the logs AI coding tools
already write to disk into per-project token analytics, with a pixel mascot living
in the notch. Native SwiftUI, no dependencies, and nothing leaves the machine.

### The banner

The sprite is my avatar, read straight out of the image so the two match, and it
writes the letters as it runs. It is generated rather than drawn:
`./tools/make-gif.sh` re-renders it from
[`tools/make.swift`](tools/make.swift), a single self contained CoreGraphics file.
Change the word on one line and run it again.
